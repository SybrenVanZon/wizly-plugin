# Wizly 0.5.1

## Watch the Angular Theming Demo

This release adds a short demo video walking through the Angular theming and runtime flow that landed in 0.5.0.

A quick recap of what 0.5.0 introduced:

- Convert Angular workspaces to SCSS and generate Material or blank theme bundles, plus reusable theme color utility classes.
- Scaffold runtime-loaded `settings.json` with a theme selector and mode toggle — switch themes without a rebuild.
- Validate the whole setup with `Check Angular Setup (Report)`.
