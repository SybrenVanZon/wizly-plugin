# Wizly 0.6.0

## Magic Colors

New command **`Wizly: Import Magic Color File (SCSS)`**:

- Point it at a Magic color file (`.eng`) and Wizly generates matching SCSS — `_magic-colors.scss` (variables) and `_magic-color-utilities.scss` (`magic-color-*` classes).
- The utilities import is wired into your `main.scss`, building straight on the SCSS/theming foundation from 0.5.0.
- Transparent backgrounds and unknown system colors are handled for you.

## Magic Dependency Check

**`Wizly: Check Angular Setup (Report)`** now also looks at your `@magic-xpa/*` packages:

- All Magic packages on one version, pinned exactly, with `@magic-xpa/cli` in `devDependencies` only.
- Every Magic package your code imports is really declared, not just resolved through another package.
- Your installed `@angular/core` still matches what the installed `@magic-xpa/angular` peers on — this is what catches a Magic release that jumps to a new Angular major.

The report only tells you what it found and how to fix it; it never edits `package.json`. The same report now also separates "declared in package.json" from "only present in node_modules" for `sass` and `@angular/material`.

See `CHANGELOG.md` for the full list of changes.
