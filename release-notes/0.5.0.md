# Wizly 0.5.0

## Angular Theming and Runtime Foundation

- Convert Angular workspaces from CSS to SCSS with Wizly's `src/scss/main.scss` structure.
- Generate Angular Material theme bundles or blank SCSS theme bundles and register them in `angular.json`.
- Generate Material color utility classes for quick theme-aware backgrounds, text, borders, and fills.
- Scaffold runtime-loaded `settings/settings.json` plus Angular startup wiring for theme loading and mode switching.
- Sync runtime theme entries from `angular.json` into `settings.json` and validate the whole setup with `Wizly: Check Angular Setup`.
