# Wizly 0.5.0

## Angular Theming and Runtime Foundation

New commands to:

- Convert Angular workspaces to SCSS, generate Material or blank theme bundles, and add reusable theme color utility classes.
- Scaffold runtime-loaded `settings.json` with Angular startup wiring, plus a theme selector and mode toggle — switch themes without a rebuild.
- Keep theme bundles in sync with `settings.json` as you add or rename them.
- Validate your whole setup with `Check Angular Setup (Report)`.

Also new: a simpler extension icon and logo. Follow `Getting Started` in the wiki for the recommended order, and see `CHANGELOG.md` for the full list of new commands.
