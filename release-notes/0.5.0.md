# Wizly 0.5.0

## Angular Theming and Runtime Foundation

- Convert Angular workspaces to a `src/scss/main.scss` structure and generate separate theme bundles in `angular.json`.
- Optionally activate the first generated single theme directly in `index.html`, while keeping runtime settings available for multi-theme setups.
- Scaffold runtime-loaded `settings/settings.json`, Angular startup wiring, theme synchronization, plus a custom theme selector and mode toggle for runtime switching.
- The wiki can help you get started with the recommended order, especially `Getting Started`.

New commands in this release:

- `Convert Angular Project to SCSS`
- `Generate Angular Material Theme (SCSS)`
- `Generate Theme Bundle (Blank SCSS)`
- `Generate Theme Color Utilities (SCSS)`
- `Setup Runtime Settings (Angular)`
- `Sync Runtime Themes (Angular)`
- `Check Angular Setup`

Also: a new, simpler extension icon and logo.
