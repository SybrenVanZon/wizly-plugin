# Wizly 0.7.0

## PWA

New command **`Wizly: Convert Angular Project to PWA`**:

- Turns your Angular project into an installable app with Angular's own PWA setup.
- Installs the service worker on the same version as your `@angular/core`, so `ng add` does not fail on version conflicts.
- Raises Angular's default production budget, which Magic-sized bundles almost always exceed.
- Optionally adds an update prompt: users see when a new version is ready and choose when to reload.

## PWA Icons

New command **`Wizly: Generate PWA Icons & Favicon (from Active Image)`**:

- Open one PNG and Wizly creates every icon from your `manifest.webmanifest`, plus `favicon.ico`.

## Check Angular Setup

The report now has a **PWA** chapter that shows whether the manifest and the service worker config are both in place.

See the PWA page in the wiki for caching Magic's `Prepare for Deployment` files and using Material Icons offline.
