# Theme Color Utilities

This page is useful when you want reusable utility classes for theme colors, instead of only using the colors inside full theme definitions.

## What Wizly Does

Main command:

- `Wizly: Generate Theme Color Utilities (SCSS)`

## What You Gain Above the Magic Baseline

Magic and Angular Material themes help define overall component styling, but they do not automatically give you a simple utility class set for direct use in templates.

Wizly adds that extra layer by:

- generating reusable Material-oriented utility classes that read CSS variables
- creating background, text, border and fill classes for both general colors and palette steps
- keeping the utility layer separate from the theme file itself
- wiring the generated file into the main SCSS entry point

## What The Command Creates

The command:

- writes `src/scss/base/_mat-color-utilities.scss`
- adds `@use './base/mat-color-utilities';` to `src/scss/main.scss` if needed
- creates utility classes that read public CSS variables such as `--wizly-mat-primary-400`

## Where The Variables Come From

The utility classes do not calculate colors by themselves.

Instead, they expect the active Angular Material theme generated by Wizly to expose variables such as:

- `--wizly-mat-primary`
- `--wizly-mat-on-primary`
- `--wizly-mat-primary-400`
- `--wizly-mat-on-primary-400`
- `--wizly-mat-secondary-700`
- `--wizly-mat-warn-A200`

## Generated Class Names

Wizly generates utility classes such as:

- `mat-bg-primary`
- `mat-text-primary`
- `mat-border-primary`
- `mat-fill-primary`
- `mat-bg-primary-400`
- `mat-text-primary-100`
- `mat-border-primary-400`
- `mat-fill-primary-400`
- `mat-text-secondary-700`
- `mat-bg-warn-500`
- `mat-text-warn-A200`

The same pattern is generated for:

- `primary`
- `secondary`
- `warn`

And for the palette steps:

- `50` to `900`
- `A100`
- `A200`
- `A400`
- `A700`

## What The Classes Do

Background classes:

- set `background-color`
- also set a matching foreground color variable for readability

Text classes:

- only set the `color`

Border classes:

- set `border-color`
- are useful when your component or helper class already defines border width and style

Fill classes:

- set `fill`
- are useful for SVG icons or other elements that read the CSS `fill` property

## Example

```html
<div class="mat-bg-primary-400">
  Branded panel with automatic readable text color
</div>

<span class="mat-text-secondary-700">
  Accent text
</span>

<div class="card-frame mat-border-primary-400">
  Border color taken from the active theme
</div>

<svg class="mat-fill-warn-A200" viewBox="0 0 24 24">
  ...
</svg>
```

## Important To Know

- These are global utility classes, so they are meant for direct use in templates.
- They depend on the public `--wizly-mat-*` variables from the active Material theme.
- If you use a blank theme bundle, you would need to provide matching variables yourself.
- If you run the command again, the generated file can be overwritten.

## Recommended Use

This is especially useful when:

- you want quick branded backgrounds in templates
- you want consistent text color helpers
- you want easy theme-aware borders and icon fills
- you want utility-style classes without writing every palette step by hand
- you still want the result to stay aligned with your theme color setup
