## Available Angular Helpers

- Check whether SCSS, themes, runtime settings, PWA markers, shared modules, and related Angular configuration look consistent
- Use the upgrade assistant to launch the right patch and Angular review steps after updating Wizly
- Convert a workspace from CSS to SCSS
- Enable PWA support
- Generate PWA icons and favicon
- Scaffold Angular Material theme files
- Scaffold blank theme bundles
- Import a Magic color file into SCSS vars and `magic-color-*` classes
- Generate theme color utility classes based on public Material theme variables
- Set up runtime settings
- Sync runtime themes
- Sync shared modules

## Recommended Order

1. `Wizly: Check Angular Setup` when you want a quick health check of the current Angular project
2. `Wizly: Convert Angular Project to SCSS`
3. `Wizly: Import Magic Color File (SCSS)` if you already maintain colors in Magic
4. `Wizly: Convert Angular Project to PWA`
5. `Wizly: Generate PWA Icons & Favicon (from Active Image)`
6. `Wizly: Generate Angular Material Theme (SCSS)` or `Wizly: Generate Theme Bundle (Blank SCSS)`
7. `Wizly: Generate Theme Color Utilities (SCSS)` if you want reusable global palette classes
8. `Wizly: Setup Runtime Settings (Angular)`
9. `Wizly: Sync Runtime Themes (Angular)`
10. `Wizly: Sync Shared Modules (Angular)`
