# Angular

Wizly also includes commands for Angular workspaces that often appear around Magic-generated front-end projects.

## Available Angular Helpers

- Convert a workspace from CSS to SCSS
- Enable PWA support
- Generate PWA icons and favicon
- Scaffold Angular Material theme files
- Scaffold blank theme bundles
- Set up runtime settings
- Sync runtime themes
- Sync shared modules

## Recommended Order

1. `Wizly: Convert Angular Project to SCSS`
2. `Wizly: Convert Angular Project to PWA`
3. `Wizly: Generate PWA Icons & Favicon (from Active Image)`
4. `Wizly: Generate Angular Material Theme (SCSS)` or `Wizly: Generate Theme Bundle (Blank SCSS)`
5. `Wizly: Setup Runtime Settings (Angular)`
6. `Wizly: Sync Runtime Themes (Angular)`
7. `Wizly: Sync Shared Modules (Angular)`
